Goal : We must implement LeNet‑5 for RGB images of shape 3×32×32. The nn.Sequential is given but every layer argument is None. We need to fill in the correct numbers by hand using the figure and the provided output-shape table.

batch(how many images) x channel x height x width


#### Formula's : Output size

n_out=⌊n+2p−k /S⌋+1

n	input size along one dimension (height, or width, or time)
k   kernel size (the sliding window)	ex. 5, 3, 2
p	padding (extra zeros added around the border)	0, 1, 2
s	stride (how far the window moves each step)	1, 2
n_out output size along that same dimension	computed

#### Formula's : Parameter counts
params=out_channels×(in_channels×k×k+1)


out_channels : amount of output feature maps to produce
kxk : size of kernel
+1 = one bias per output channel.


#### Example
Input : grayscale (1-channel) 8x8 image.
Convolution : 
- input_channel=1 : fixed by the input
- out_channels=4  : so we'd need 4 different kernels and get 4 feature maps.
- kernel_size=3   : each kernel is 3x3

- Choose the padding and stride : def. p=0, s=1
