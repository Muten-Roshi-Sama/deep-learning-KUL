## Exercise 1 (images, 2D). 
Compute the layer parameters of LeNet-5 for colour images by hand, then adapt a pretrained ResNet18 to CIFAR-10: skip its last stage, add your own output layer, and train only that layer.

**Data:** CIFAR-10, 60,000 colour images of 32 × 32 pixels in 10 classes. The training images are
split into 45,000 for training and 5,000 for validation; the official 10,000 test images are only used
at the end.


### `01_prepare_data.py`
Run :
```bash
python /data/leuven/394/vsc39441/deep_learning/Lab2/Code/exercise1_image_2d/01_prepare_data.py

# Output

  shape = (images, height, width, colour channels)
Pixel values: min 0, max 255

# Observe 10 classes of 5000 instances each.

Train:       45000 images
Validation:   5000 images
Final test:  10000 images (official test set)
```


### `02_train_scratch_cnn.py`
Goal : We must implement LeNet‑5 for RGB images of shape 3×32×32. The nn.Sequential is given but every layer argument is None. We need to fill in the correct numbers by hand using the figure and the provided output-shape table.
